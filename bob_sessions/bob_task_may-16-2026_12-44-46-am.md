**Implement these merge functions — do not leave them undefined:**
```js
function mergeBobWithParser(bobData, parserData) {
  // Build a lookup of parserData nodes by id
  const parserMap = Object.fromEntries(parserData.nodes.map(n => [n.id, n]));

  const mergedNodes = bobData.nodes.map(bobNode => ({
    ...bobNode,
    // importCount ALWAYS comes from parserData — never from Bob
    importCount: parserMap[bobNode.id]?.importCount ?? 0,
  }));

  // Add any parserData nodes Bob missed entirely
  parserData.nodes.forEach(pNode => {
    if (!mergedNodes.find(n => n.id === pNode.id)) {
      mergedNodes.push(pNode);
    }
  });

  return { ...bobData, nodes: mergedNodes };
}

// mergeGroqWithParser follows the identical pattern
function mergeGroqWithParser(groqData, parserData) {
  return mergeBobWithParser(groqData, parserData);
}
```
Never overwrite `importCount` — it must always come from parserData where it was calculated.

## 3. Key Technical Concepts

- **4-Level Fallback Pipeline**: IBM Bob → Groq API → Parser data → Demo data (ensures demo never fails)
- **BFS Wave System**: 3-depth blast radius calculation with timed animations (0ms, 420ms, 800ms)
- **D3 Force Simulation**: Interactive graph with strengthened forces (-600 charge, 120 distance, 40 collision radius)
- **CSS Drop-Shadow**: Node glow effects using `drop-shadow()` filter instead of SVG filters
- **Curved Bezier Links**: `linkArc` function using quadratic curves for connection paths
- **focusModeRef Pattern**: React ref to avoid stale closure bugs in D3 event handlers
- **requestAnimationFrame**: Used for node click interactions instead of setTimeout
- **Relative API Paths**: Frontend uses `/api/*` which Vite proxies in dev, Vercel routes in production
- **Import Count Preservation**: Merge functions always preserve importCount from parser data
- **Supabase Try/Catch**: All Supabase saves wrapped to prevent crashes

## 5. Problem Solving

**Issue 1: Blast radius showing 3 instead of 14**
- Root cause: Backend DEMO_DATA only had 6 nodes
- Solution: Updated server.js DEMO_DATA to include all 18 nodes and 32 links matching frontend exactly

**Issue 2: Risk filter breaking graph**
- Root cause: GraphPage.jsx filtered nodes array before passing to Graph, creating orphaned links
- Solution: Pass riskFilter prop to Graph component which dims non-matching nodes to 4% opacity instead

**Issue 3: Hardcoded localhost URLs**
- Root cause: Loading.jsx and ImpactPanel.jsx used `http://localhost:3001/api/*`
- Solution: Changed to relative paths `/api/*`, added Vite proxy for development

**Issue 4: Graph.jsx line 530 selector bug**
- Root cause: Used `svg.selectAll("line")` but links are `<path>` elements
- Solution: Changed to `svg.selectAll("path")` for focus mode dimming

**Issue 5: Supabase failures crashing analysis**
- Root cause: Unprotected `await saveToSupabase()` calls in bobIntegration.js and groqFallback.js
- Solution: Wrapped both in try/catch blocks so Supabase failures never crash core analysis

**Issue 6: SVG node glow not rendering**
- Root cause: SVG feGaussianBlur filters not displaying in browser
- Solution: Replaced with CSS drop-shadow filter which works on SVG elements in modern browsers

**Issue 7: Network errors causing infinite loading**
- Root cause: fetch() has no timeout, hangs indefinitely when WiFi is off
- Solution: Added Promise.race with 30-second timeout, error UI with Try Again button

**Issue 8: .gitignore missing .env protection**
- Root cause: .gitignore didn't exclude .env files or temp directories
- Solution: Added .env, .env.local, backend/.env, backend/temp/ exclusions

**Issue 9: README.md in wrong location**
- Root cause: README.md existed inside bob_sessions/ folder
- Solution: Removed bob_sessions/README.md (main README.md already exists in project root)
